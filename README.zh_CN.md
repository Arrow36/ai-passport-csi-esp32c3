# AI Passport CSI · ESP32-C3

仓库名：`ai-passport-csi-esp32c3`

**把 AI Passport 变成一台便携式 Wi-Fi CSI 观察仪。**

基于 [FoloToy AI Passport](https://github.com/FoloToy/ai-passport) 的实验性固件，使用 ESP32-C3 采集 Wi-Fi 信道状态信息（Channel State Information，CSI），在设备屏幕上展示信号幅度和相对环境扰动，探索无线信号如何随周围环境变化。

适合用于学习 CSI、观察环境变化，以及开展 Wi-Fi 感知实验。

> 当前版本是幅度与扰动观察原型。它不能生成房间地图、三维点云、人体轮廓或人员坐标；扰动分数也不代表有人概率。

此预览使用模拟数据，不是真机采样截图。

## 功能

- **实时幅度曲线**：观察约 10 秒内的 CSI 幅度变化。
- **子载波幅度图**：展示所选 42 个子载波的幅度分布。
- **背景校准**：以静态环境作为参考，计算 0–100 的相对扰动分数。
- **采样状态**：显示有效接收、队列丢帧、无效帧及实际采样速率。
- **中文界面和本地配网**：手机连接设备热点，通过网页设置路由器连接。
- **设备按键操作**：切换图表、暂停显示、重新校准和重新配网。

## 准备什么

| 项目 | 要求 |
| --- | --- |
| 设备 | FoloToy AI Passport，ESP32-C3，8 MB Flash |
| 路由器 | 2.4 GHz Wi-Fi，支持所需的 20 MHz OFDM/HT 数据包，网关可响应 Ping |
| 手机 | 用于首次本地配网 |
| USB 数据线与电脑 | 用于编译、烧录和查看日志 |
| 开发环境 | ESP-IDF 5.5.3，以及项目锁定的依赖 |

采样需要连接路由器，**不需要路由器接入互联网**。实际兼容性和采样速率取决于路由器及无线链路。

## 工作原理

```text
AI Passport ──周期性 Ping──▶ 路由器
AI Passport ◀──Wi-Fi 回包── 路由器
     │
     └─ CSI I/Q → 子载波幅度 → 背景比较 → 屏幕图表
```

Wi-Fi 信号传播时会受到遮挡和多径反射影响。程序从接收包中提取 CSI，选取 42 个子载波计算幅度，并比较归一化后的幅度形状与背景参考。

人走动、宠物、风扇、家具变化、无线干扰和设备自身移动都可能影响读数。实验时请固定设备与路由器的位置。

## 编译与烧录

以下命令在已加载 ESP-IDF 5.5.3 环境的终端中执行。验证脚本需要 Bash；Windows 环境配置见项目开发文档。

```bash
idf.py set-target esp32c3
./tools/validate.sh --firmware
```

验证成功后，合并镜像位于 `build/FoloToy-AI-Passport-full.bin`，烧录偏移为 `0x0`。该镜像会替换原固件，并可能重置设备中的已有设置；需要保留的设置请事先保存。

增量开发可使用：

```bash
idf.py build
idf.py -p <PORT> flash monitor
```

详细说明见 [编译与测试](docs/development/engineering/build-and-test.zh_CN.md)。

## 开始实验

1. 开机，用手机连接屏幕显示的 `CSI-Passport-XXXX` 热点，输入屏幕上的密码。
2. 手机提示没有互联网时保持连接，打开 `http://192.168.4.1`。
3. 填入 2.4 GHz 路由器的 Wi-Fi 名称和密码。
4. 连接成功后，固定设备与路由器，保持环境安静，等待背景校准完成。校准至少需要 8 秒及 100 个有效样本。
5. 在设备和路由器之间走动，对比静态环境与活动时的曲线和扰动分数。

Wi-Fi 凭证保存在设备本地。成功连接后，设备关闭配网热点与网页服务。

| 按键 | 操作 |
| --- | --- |
| 上键 | 切换时间曲线与子载波幅度图 |
| 下键 | 暂停或继续图表显示，采集与分数仍继续更新 |
| 确定键 | 重新校准背景 |
| 长按确定键 | 打开配网，暂停采样 |
| 配网时按确定键 | 若仍连接路由器，返回采样 |
| 配网时长按下键 | 清除此应用保存的 Wi-Fi 凭证 |

## 如何理解读数

- **幅度**：任意单位，不是 dBm、距离或经过校准的场强。
- **扰动分数**：相对于背景的实验指标，不是人员数量、存在概率或经过验证的检测结果。
- **采样速率**：实测值。程序以 10 ms 为目标 Ping 间隔，不保证每秒收到固定数量的有效 CSI。
- **无数据**：超过 1.5 秒没有有效 CSI 时显示；数据恢复后重新学习背景。

距离、灵敏度、误报率和续航仍需要系统实测。当前版本尚未实现定位、呼吸检测或动作识别。
