# CSI Scope 0.1

适用于 ESP32-C3 FoloToy AI Passport 的 CSI 幅度与相对扰动观察原型。
基于上游 `0b9e4c81ee4421c0bac39ca3561d65a8285acd4a`，分支为
`feature/csi-scope`，使用 ESP-IDF 5.5.3 和项目锁定的依赖。
采用独立的应用界面，不使用原来的硬件测试菜单。

## 配网和按键

1. 经同意烧录后开机，用手机连接屏幕上的 `CSI-Passport-XXXX` 热点，
   输入屏幕显示的随机密码。
2. 提示“无互联网”时继续连接，手动打开 `http://192.168.4.1`，
   填入 2.4 GHz 路由器的 Wi-Fi 名称和密码并提交。
3. 路由器凭证只保存在设备上，成功连接并取得 IP 后才保存。错误的密码
   不覆盖上一组可用凭证。成功后关闭配网热点和网页服务，不使用云服务。
4. 固定路由器和设备，保持环境安静以完成校准：至少 8 秒及 100 个有效样本。
5. 在设备和路由器之间走动，与空房间的波形和分数作对比。

| 按键 | 功能 |
| --- | --- |
| 上键 | 切换约 10 秒时间曲线和子载波幅度图 |
| 下键 | 暂停/继续显示曲线，采集和分数继续更新 |
| 确定键 | 重新校准背景 |
| 长按确定键 | 打开配网并暂停采样 |
| 配网时按确定键 | 若仍连接路由器，则返回采样 |
| 配网时长按下键 | 清除此应用保存的 Wi-Fi 凭证 |

设备和手机配网页面均为简体中文，设备使用已验证覆盖范围的
[12/14 像素中文子集字库](../assets/fonts/README.zh_CN.md)。电量计不可用时显示
`USB`，这不代表测得充电状态。“接收”是有效帧数，“丢弃”是队列丢帧数，
“无效”是不兼容、无效或严重饱和的帧数。包速率显示实测值，不承诺固定速率。

## 数据含义和限制

关闭 Wi-Fi 省电，以 10 ms 的目标间隔 Ping 本地网关，实际采样率取决于路由器
和链路。只接收所连路由器 BSSID 的 20 MHz OFDM/HT LLTF CSI。回调复制
128 字节到有界队列，信号处理在 Wi-Fi 任务之外进行。选择 42 个子载波，
避开直流、保护区和可能无效的首字。关闭未使用的蓝牙和音频以节约内存。

时间曲线显示 CSI 原始幅度均值，单位为任意单位，不是 RSSI、距离或校准过的
场强。子载波图按所选负频率、正频率顺序排列，省略中间直流附近的空隙。
扰动分数比较 RMS 归一化后的幅度形状与缓慢变化的参考，再减去校准噪声底。
整体增益变化会受到抑制，但 AGC、干扰、人、宠物、风扇、设备移动和家具变化
都可能影响读数。0–100 只是实验性的相对指标，不是有人概率或经过验证的探测器。

超过 1.5 秒没有有效 CSI 时显示无数据，而不是零扰动。恢复后重新学习背景。
接收数一直为零时检查网关是否响应 Ping、路由器是否支持 20 MHz OFDM/802.11n；
无效帧数可辅助判断是否收到不兼容帧。距离、灵敏度、采样率和续航需要实机测量。

## 验证和烧录

运行 `tools/validate.sh`。`tests/test_csi_model.c` 覆盖幅度计算、增益归一化、
多径形状变化、校准、断流、计时回绕和凭证长度边界；主机测试不代表射频实测。

默认 8 MB 分区表不变。取得明确同意后，将校验过的合并 `full.bin` 烧录到
`0x0`。合并镜像会覆盖原应用，其填充区域可能重置 NVS/PHY 中的设置。
无需先全片擦除。`tools/archive_firmware.py` 同时保留对应固件和 ELF/MAP。

Windows 主机检查需要 Git Bash、实际的 Python 3、MinGW GCC，以及通过
`ACTIONLINT_BIN` 指定的 Windows actionlint。检查脚本为 MinGW 运行时测试
关闭会保留无用函数的展开表，并统一检查信息中的路径分隔符。
工作目录较长时，编译器头文件可能需要短路径来避开 Windows 工具链路径限制。

待实机验收：开机和显示、全部按键、手机配网、密码错误恢复、重启及重连、
有效 CSI 速率、校准、走动响应、暂停曲线、断流提示、重复配网及内存稳定性。
